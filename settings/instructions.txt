# X axis represents left-right movement
# Y axis represents up-down movement
# Z axis represents extrusion of wire
#
# SERVO CUT
# this command moves the servo to cut the wire
#
# SOLENOID {time}
# this command, for example, SOLENOID 001 pulls in solenoid for 1 second
#
# PUMPX {time}
# this command, for example, PUMP1 010 turns on pump1 for 10 seconds
#
# FAN {time}
# this command, for example, FAN 035 turns on pump1 for 35 seconds
#
# SPECTRUM GET
# this command gets spectrometer data in list format
#
# PAUSE {time}
# this command, for example, PAUSE 035 makes a 30 second pause before executing next command
#
G90

#Move head below extruder
G1 X-49 Y68
PAUSE 010

#Turn on solenoid
SOLENOID 010

#Extrude 10cm wire
G91
G1 Z40

#Cut the wire
SERVO CUT
